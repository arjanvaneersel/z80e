# Step 2: Register Pair Operations and Helper Methods

## Learning Goal
Understand how the Z80 combines 8-bit registers into 16-bit register pairs and implement safe, convenient methods for accessing them. Learn about endianness in CPU registers and establish patterns for register manipulation.

## Background: Z80 Register Pairs
The Z80 frequently operates on register pairs as 16-bit values:
- AF = A (high) + F (low) - Accumulator + Flags
- BC = B (high) + C (low) - General purpose pair
- DE = D (high) + E (low) - General purpose pair
- HL = H (high) + L (low) - Memory pointer pair (most important!)

Key concept: In Z80 register pairs, the first letter is the high byte:

BC = (B << 8) | C
HL = (H << 8) | L

## The Tests
Add these tests to your tests module:
```rust
#[test]
fn test_register_pair_getters() {
    let mut cpu = Z80::new();
    
    // Set up test values
    cpu.a = 0x12; cpu.f = 0x34;
    cpu.b = 0x56; cpu.c = 0x78;
    cpu.d = 0x9A; cpu.e = 0xBC;
    cpu.h = 0xDE; cpu.l = 0xF0;
    
    // Test register pair getters
    assert_eq!(cpu.af(), 0x1234);  // A=high, F=low
    assert_eq!(cpu.bc(), 0x5678);  // B=high, C=low
    assert_eq!(cpu.de(), 0x9ABC);  // D=high, E=low
    assert_eq!(cpu.hl(), 0xDEF0);  // H=high, L=low
}

#[test]
fn test_register_pair_setters() {
    let mut cpu = Z80::new();
    
    // Set register pairs
    cpu.set_af(0x1234);
    cpu.set_bc(0x5678);
    cpu.set_de(0x9ABC);
    cpu.set_hl(0xDEF0);
    
    // Verify individual registers were set correctly
    assert_eq!(cpu.a, 0x12); assert_eq!(cpu.f, 0x34);
    assert_eq!(cpu.b, 0x56); assert_eq!(cpu.c, 0x78);
    assert_eq!(cpu.d, 0x9A); assert_eq!(cpu.e, 0xBC);
    assert_eq!(cpu.h, 0xDE); assert_eq!(cpu.l, 0xF0);
}

#[test]
fn test_register_pair_roundtrip() {
    let mut cpu = Z80::new();
    
    // Test that get/set operations are consistent
    cpu.set_bc(0xABCD);
    assert_eq!(cpu.bc(), 0xABCD);
    
    cpu.set_hl(0x1234);
    assert_eq!(cpu.hl(), 0x1234);
    
    // Test edge cases
    cpu.set_af(0x0000);
    assert_eq!(cpu.af(), 0x0000);
    
    cpu.set_de(0xFFFF);
    assert_eq!(cpu.de(), 0xFFFF);
}
```

## What These Tests Verify

- Correct bit manipulation: High byte goes to first register, low byte to second
- Bidirectional operations: Both getting and setting register pairs work
- Consistency: Round-trip operations (set then get) return the same value
- Edge cases: Minimum (0x0000) and maximum (0xFFFF) values work correctly
- All register pairs: Every main register pair is supported

## Design Decisions Explained
### Why separate getter/setter methods?

Clarity: Makes register pair access explicit and intentional
Safety: Prevents accidental modification of half a register pair
Debugging: Easy to set breakpoints on register pair access
Future-proofing: We can add validation or logging later

### Why this bit pattern?
```rust
// For BC pair (B=high, C=low):
bc() -> u16 { (self.b as u16) << 8 | self.c as u16 }
set_bc(value: u16) { 
    self.b = (value >> 8) as u8;   // High byte
    self.c = value as u8;          // Low byte (truncates automatically)
}
```

Alternative register pairs: Note that IX and IY are already u16, so they don't need pair methods.

## Why This Step Matters
These helper methods will be essential for:

- 16-bit arithmetic instructions (ADD HL, BC)
- Memory addressing (LD A, (HL))
- Stack operations (PUSH BC, POP DE)
- Jump instructions (JP (HL))
